Dispatch

Run any substrate call from an EVM account. The call goes through the EVM dispatch precompile with the account's own origin, so it is what an account without a substrate key uses for governance, committee proposals, or anything else built off chain. Sign with Rabby or MetaMask, Trezor through Rabby.
